# Is the best model biased towards surface measures? The best set without them

Generated by `curated_features/modeling/run_surface_ablation.py`. The cognitive features (sentence length, and the old parse features that include tokens per sentence) carry more than half of the best model's importance, and the labels follow word and sentence length closely. Here they are removed step by step. Gradient boosting; test = the 865 real-Finnish test texts.

## Summary

- The best set misses by 0.257 on the test set (trained on real-Finnish rows). Without all cognitive features: 0.382; also without the length-like vocab features: 0.425.
- On `FI` alone (labels vary, the source cannot explain them), trained on FI rows: 0.277 for the best set, 0.409 without the cognitive features, 0.395 without the length-like vocab features too; a constant guess gives 1.287 and the 4 surface measures 0.398.

## How to read the numbers

- **Average miss (MAE)** with a 95% interval from resampling the texts; smaller is better. One label step is 0.5.
- **FI only** is graded on the 310 FI test texts after training on the FI train rows only (729 texts): the one source whose labels vary, so recognising the source does not help.
- **Length-like vocab features**: `avg_word_length`, `long_word_ratio`, `n_unique_lemmas` (grows with text length) and `n_compound_tokens` (a count).
