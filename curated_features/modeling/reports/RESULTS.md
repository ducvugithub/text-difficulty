# Results: which features predict text difficulty?

Generated by `curated_features/modeling/make_results_report.py` from the run outputs in `curated_features/modeling/reports/runs/`; no number is typed by hand. `(new)` = features built in this repository, `(old)` = the columns that come with the data.

## Summary

We predict a Finnish text's difficulty (label 1 to 6) from groups of features and compare the average error.

- Best: **vocab + grammar_coverage + cognitive (new)** (311 features), average miss 0.257, against 0.374 for the 402 original columns, 0.354 for the surface baseline (intervals do not overlap) and 1.284 for a constant guess.
- Grammar works best as the share of each concept (0.460), not as manual levels (0.821) or rarity (0.793).
- The new vocabulary features (0.471) beat the old vocabulary bins (0.909).
- Caution: the surface baseline (word and sentence length) is already a strong clue, so part of every score may come from such simple measures or from the source of the texts, not from deeper difficulty.

## How to read the numbers

- **Average miss (MAE)**: average distance between predicted and true label; smaller is better. One label step is 0.5.
- **Exactly right / within one step**: the prediction, rounded to the nearest half step, equals the label / is off by at most 0.5.
- **95% interval**: from resampling the 865 test texts; overlapping intervals may be noise.
- **Constant guess**: always the same label. The floor.

| surface | the text itself | new |
| original: vocab bins, grammar columns | the columns that come with the data | old |

So the grammar features and the parse features rely on an older Revita run. For a new text, the Revita analyser would be needed to produce them; it works, but its output differs somewhat from the old columns.
