# Frozen BERT embeddings, layer by layer

Generated by `bert/run_layers.py`. Model: `TurkuNLP/bert-base-finnish-cased-v1`, frozen (nothing is fine-tuned).

## Summary

- Trained on real-Finnish rows (2,332 texts): the best layer is **layer 5** with an average miss of **0.389** (layer 0: 0.481, layer 12: 0.404; a constant guess: 1.284). The best curated feature set misses by 0.268 with gradient boosting and by 0.518 with ridge regression (the model used here).
- Trained on all rows (8,293 texts): the best layer is **layer 11** with an average miss of **0.467** (layer 0: 0.603, layer 12: 0.474; a constant guess: 1.605). The best curated feature set misses by 0.350 with gradient boosting and by 0.639 with ridge regression (the model used here).

## How to read the numbers

- **Average miss (MAE)**: average distance between predicted and true label; smaller is better. One label step is 0.5.
- **Exactly right / within one step**: the prediction, rounded to the nearest half step, equals the label / is off by at most 0.5.
- **95% interval**: from resampling the 865 test texts; overlapping intervals may be noise.
- Layer 0 is the word-piece embedding layer, before any transformer layer; layers 1 to 12 are the transformer layers.

## Setup

- Model `TurkuNLP/bert-base-finnish-cased-v1`, 12 transformer layers, 768 dimensions. Frozen: the embeddings are computed once (`bert/embeddings.py`).
- Each text is cut into windows of at most 510 word-pieces; for each layer the hidden states of all word-pieces of the text are averaged (one vector of 768 numbers per text and layer).
- Regressor: ridge regression on standardised embeddings, regularisation chosen by leave-one-out cross-validation on the training texts.
- Test set: the same 865 real-Finnish texts as in the curated results, so the numbers are comparable with `curated/modeling/reports/RESULTS.md`.
