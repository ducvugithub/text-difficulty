# grammar-diff — syntactic / morphological complexity

Candidates (some already exist as columns in data/*.csv: average_tree_depth, average_num_pos, Noun-Paradigm-*, case_ratio_*):
- Syntax: tree depth, sentence length, clause count, subordination ratio, passive / participial constructions
- Morphology: case distribution (rare cases: abl, ess, tra, abe, com), paradigm rarity, verb forms (conditional, potential, infinitives, participles)
- Compounding and derivation load per sentence
- Word order irregularity (non-SVO), ellipsis, zero-person constructions
- CEFR grammar-point tagging (which structures appear at which level)
