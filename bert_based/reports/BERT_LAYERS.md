# Frozen BERT embeddings, layer by layer

Generated by `bert_based/run_layers.py`. Model: `TurkuNLP/bert-base-finnish-cased-v1`, frozen (nothing is fine-tuned).

## Summary

- Trained on real-Finnish rows (2,332 texts): the best layer is **layer 5** with an average miss of **0.389 (7.8%)** (layer 0: 0.481 (9.6%), layer 12: 0.404 (8.1%); a constant guess: 1.284 (25.7%)). The best curated feature set misses by 0.257 (5.1%) with gradient boosting and by 0.513 (10.3%) with ridge regression (the model used here).
- Trained on all rows (8,293 texts): the best layer is **layer 11** with an average miss of **0.467 (9.3%)** (layer 0: 0.603 (12.1%), layer 12: 0.474 (9.5%); a constant guess: 1.605 (32.1%)). The best curated feature set misses by 0.333 (6.7%) with gradient boosting and by 0.626 (12.5%) with ridge regression (the model used here).

## How to read the numbers

- **Average miss (MAE)**: average distance between predicted and true label; smaller is better. One label step is 0.5. A percent in brackets after an average miss is that miss divided by the label range (5 points, labels 1 to 6).
- **Exactly right / within one step**: the prediction, rounded to the nearest half step, equals the label / is off by at most 0.5.
- **95% interval**: from resampling the 865 test texts; overlapping intervals may be noise.
- Layer 0 is the word-piece embedding layer, before any transformer layer; layers 1 to 12 are the transformer layers.

## Setup

- Model `TurkuNLP/bert-base-finnish-cased-v1`, 12 transformer layers, 768 dimensions. Frozen: the embeddings are computed once (`bert_based/embeddings.py`).
- Each text is cut into windows of at most 510 word-pieces; for each layer the hidden states of all word-pieces of the text are averaged (one vector of 768 numbers per text and layer).
- Regressor: ridge regression on standardised embeddings, regularisation chosen by leave-one-out cross-validation on the training texts.
- Test set: the same 865 real-Finnish texts as in the curated results, so the numbers are comparable with `curated_features/modeling/reports/RESULTS.md`.
